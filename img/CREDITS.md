# Image credits

All 12 dumbbell exercise photos and most bodyweight photos are AI-generated with Figma
(gpt-image-2.5-flare, file "Mizan exercise photos", 2026-11-22), from the prompts in
`img/prompts.json` with one fixed athlete description so the same person appears in every photo.

Photos not yet regenerated in Figma (credits ran out; pending) are the earlier AI-generated set.
Sketches in `sketch/` are drawn by `tools/sketches.js` and are the fallback when a photo is missing.

The 11 floor-move photos (crunches, bicycle, planks, flutter-kicks, russian-twists, mountain-climbers, wall-sits,
calf-raises, glute-kicks, supermans, pike-pushups) are AI-generated with Figma (gpt-image-2.5-flare, file
"Mizan exercise photos: floor moves", 2026-11-24), same athlete description. The 22 other steps of those groups (dead-bugs, knee-planks, fire-hydrants and so on)
were generated the same way on 2026-11-25, so every step has its own photo; the step a group photo already shows
(for example basic crunches) uses the group photo.
